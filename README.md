Hi Welcome to the FuRRRy cookie generator!
The goal here is to generate a bunch of animal cookies. You can generate cookie recipes for dogs, cats and birds!
It starts from 837 human cookie recipes scraped from YouTube and TikTok
mutates them with ingredients from the actual diet of the chosen animal: 
the ingredient lists of 2,719 commercial cat, dog and bird food products.
A fitness function rewards cookie-like structure, plausible amounts, human edibility,
safety for the animal and a recognisable animal character

REQUIREMENTS:
	Minimum	Recommended
Operating system	Windows 10, macOS 11 or Linux (64-bit)	any recent version
Python	3.10	3.11 or 3.12
CPU	any dual-core from the last ~10 years	—
Memory (RAM)	4 GB	8 GB if you use PyCharm
Free disk space	1 GB (repo 275 MB + packages ~460 MB)	2 GB
Browser	any modern browser (Chrome, Firefox, Safari, Edge) for the interface	—
Internet	only once, to install the packages	—

INSTALLATION:
git clone https://github.com/Foppr/CC_cookies.git
cd CC_cookies
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

RUN IT:
cd "Animal Cookie EA"
python run_interface.py

Disclaimer:
The toxicity and edibility labels are our own judgement, based on public pet-safety sources.
The recipes are generated by an algorithm and have not been tested by a vet. 
Check with your vet before giving any new food to an animal, and only in small amounts.
